飞书应用凭证

飞书群机器人（Webhook）本身无法上传图片。青鸟需要借助一个自建的飞书应用去调用 POST /open-apis/im/v1/images 换取 image_key，再由群机器人发出。凭证只保存在本地。

App ID*
在飞书开放平台 · 「凭证与基础信息」中获取，形如 cli_xxxxxxxx
App Secret*
仅本地存储（macOS Keychain / Windows Credential Locker），不会上传到任何服务器。如何获取 →
已连接 · TK 应用（tk-inner-bot） 3 / 4 项就绪 3 秒前校验
  • tenant_access_token 可获取
  • bot:v3:info 可访问
  • im:resource:upload 已开通

缺少云空间权限

两端机器无法直连时，青鸟需要用飞书云空间中转文件。缺 drive:drive 权限的这段时间，只有同一网络内的机器能互传。申请后必须发布新版本才会生效。

文件传输

在内网机与外网机之间互传文件。传输是端到端加密的：文件在发送方机器上加密，只有配过对的接收方机器能解开，飞书和群里的其他人拿到的都是密文。

配置端口
实际绑定 127.0.0.1:9876
群消息里的链接一律用实际绑定端口生成。改端口需要保存并重启服务，重启后此前发出的旧链接会失效 —— 端口被占用时青鸟不会自动换端口，只会明确告诉你是谁占着。
随青鸟常驻后台关闭窗口后服务继续监听，群里的链接才点得开

轮换主密钥
